### SkyCast – Advanced Weather Dashboard
## Project Overview
SkyCast is a modern and responsive weather dashboard web application that provides real-time weather information using OpenWeatherMap API.

# The application displays / Features:
1. current weather
2. hourly forecast
3. 5-day forecast
4. AQI (Air Quality Index)
5. interactive maps
6. weather insights
7. animated weather effects
# It also includes dark/light mode, dynamic backgrounds, geolocation support, and a premium glassmorphism UI.

### Features
## Real-Time Weather
Search weather using city name
Current location weather using Geolocation API

# Displays:
1. Temperature
2. Humidity
3. Wind Speed
4. Feels Like
5. Visibility
6. Sunrise & Sunset
7. Weather Condition
   
## Hourly Forecast
Displays upcoming hourly weather updates
Dynamic horizontal forecast cards

## 5-Day Forecast
Shows upcoming daily weather conditions

## Air Quality Index (AQI)
Real-time AQI status

# AQI categories:
1. Good
2. Fair
3. Moderate
4. Poor
5. Very Poor
   
## Interactive Weather Map
Live map integration using Leaflet.js
Dynamic city location marker

## Animated Weather Effects
Rain animation during rainy weather
Dynamic weather backgrounds

## Dark / Light Mode
Theme toggle support
Improved user experience

## Smart Weather Insights
Generates weather suggestions dynamically
Example:
Plain text
🌧 Carry an umbrella today.
🥵 Stay hydrated in hot weather.
